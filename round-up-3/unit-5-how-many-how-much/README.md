## Unit at a glance

- **In the book:** Round-Up 3, Unit 5 — Expressing quantity
- **Vocabulary:** eggs, apples, tomatoes, bananas, milk, water, bread, rice, cheese, honey
- **Grammar:** some (+) and any (− ?): There are some eggs. There isn't any milk. Is there any bread?
- **Grammar:** How many + plural / How much + uncountable
- **Grammar:** a lot of, many, much, a few, a little

## Lessons

1. some and any — *Countable and uncountable nouns; some (+), any (− ?)*
2. How many? How much? — *How many + plural, How much + uncountable; many / much*
3. a lot of, a few, a little — *Quantities: a lot of, a few, a little — at the bazaar*
