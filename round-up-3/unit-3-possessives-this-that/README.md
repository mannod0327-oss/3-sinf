## Unit at a glance

- **In the book:** Round-Up 3, Unit 3 — Possessives / Demonstratives
- **Vocabulary:** pen, pencil, book, bag, ruler, notebook, scissors, computer, chair, desk
- **Grammar:** my, your, his, her, its, our, their + noun; Aziz's book
- **Grammar:** mine, yours, his, hers, ours, theirs (without a noun)
- **Grammar:** this / these (near) — that / those (far)

## Lessons

1. my, your, his, her, our, their — *Possessive adjectives and possessive 's*
2. mine, yours, his, hers — *Possessive pronouns: This pen is mine.*
3. this, that, these, those — *Near and far; one and many*
